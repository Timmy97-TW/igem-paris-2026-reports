# Photos

Name files `<team>_<what>.jpg` — e.g. `NU-Kazakhstan_reader.jpg`, `WIST_poster-wide.jpg`.

Three frames per team: poster wide · the one figure that matters · something with the team name
legible.

Ask before photographing people, and ask before photographing anything that may be unpublished.

Raw camera dumps go in `photos/raw/`, which is gitignored. Only put the keepers under version
control.
